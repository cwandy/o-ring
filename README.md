# O-Ring / Conta Yuvası Tasarım Programı

Statik (ileride dinamik) o-ring yuvası tasarımı, kontrolü ve standart ölçü önerisi için mühendislik
aracı. Odak: kriyojenik itki sistemleri (LOX, LN2, LH2, LCH4). Proje tanımı ve kararlar: `SPEC.md`.

## Kurulum

```bash
uv sync
```

## Testler

```bash
uv run pytest
```

## Arayüz

```bash
uv run streamlit run app/streamlit_app.py
```
